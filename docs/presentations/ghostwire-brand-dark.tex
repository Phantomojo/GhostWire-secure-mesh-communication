% ── Deferred setup ─────────────────────────────────────────────
% Called from the document body, where every package the template loads is
% available. Applies table and TOC styling.
% pandoc's template does not load tocloft; the header does, so \gwdocsetup can
% restyle the TOC. \usepackage is illegal in the document body, hence the split.
\newcommand{\gwdocsetup}{%
  % Row spacing: pandoc's own template already sets \arraystretch after
  % loading array, and setting it from a header-include races that load.
  % Leaving it at the template default is correct, not an omission.
  % Booktabs rules are deliberately left at their defaults. They expand to
  % \noalign, which is only legal inside an alignment, so they cannot be
  % redefined or wrapped in \textcolor from the preamble. On the dark ground
  % the default rules read as light hairlines, which is the correct weight
  % anyway. Colouring them would need \noalign-safe redefinition per table.
  % Row banding and \arrayrulecolor are deliberately omitted: both need
  % xcolor's 'table' option, which pandoc's own \usepackage{xcolor} (loaded
  % after this header) drops. Booktabs rules carry the table structure.
  %
  \renewcommand{\cftsecfont}{\color{GWInk}}%
  \renewcommand{\cftsecpagefont}{\color{GWGreen}}%
  \setlength{\cftbeforesecskip}{6pt}%
}
