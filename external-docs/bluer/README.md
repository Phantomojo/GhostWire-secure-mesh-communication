This library provides the official Rust interface to the [Linux Bluetooth protocol stack (BlueZ)](http://www.bluez.org/). Both publishing local and consuming remote [GATT services](https://www.oreilly.com/library/view/getting-started-with/9781491900550/ch04.html) using idiomatic Rust code is supported. L2CAP and RFCOMM sockets are presented using an API similar to Tokio networking.
This library depends on the [tokio](https://docs.rs/tokio/1.47.1/x86_64-unknown-linux-gnu/tokio/index.html) asynchronous runtime.

### [§](https://docs.rs/bluer/latest/bluer/#crate-features)Crate features
[§](https://docs.rs/bluer/latest/bluer/#crate-features)
The following crate features are available.
- bluetoothd: Enables all functions requiring a running Bluetooth daemon.
- id: Enables database of assigned numbers.
- l2cap: Enables L2CAP sockets.
- rfcomm: Enables RFCOMM sockets.
- mesh: Enables Bluetooth mesh functionality.
- serde: Enables serialization and deserialization of some data types.

### [§](https://docs.rs/bluer/latest/bluer/#basic-usage)Basic usage
[§](https://docs.rs/bluer/latest/bluer/#basic-usage)
Create a [Session](https://docs.rs/bluer/latest/bluer/struct.Session.html) using [Session::new](https://docs.rs/bluer/latest/bluer/struct.Session.html#method.new); this establishes a connection to the Bluetooth daemon. Then obtain a Bluetooth adapter using [Session::adapter](https://docs.rs/bluer/latest/bluer/struct.Session.html#method.adapter). From there on you can access most of the functionality using the methods provided by [Adapter](https://docs.rs/bluer/latest/bluer/struct.Adapter.html).

### [§](https://docs.rs/bluer/latest/bluer/#l2cap-and-rfcomm-sockets)L2CAP and RFCOMM sockets
[§](https://docs.rs/bluer/latest/bluer/#l2cap-and-rfcomm-sockets)
Refer to the [l2cap](https://docs.rs/bluer/latest/bluer/l2cap/index.html) and [rfcomm](https://docs.rs/bluer/latest/bluer/rfcomm/index.html) modules. No [Session](https://docs.rs/bluer/latest/bluer/struct.Session.html) and therefore no running Bluetooth daemon is required.
