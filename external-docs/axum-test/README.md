Axum Test is a library for writing tests for web servers written using Axum:
- You create a [TestServer](https://docs.rs/axum-test/latest/axum_test/struct.TestServer.html) within a test,
- use that to build [TestRequest](https://docs.rs/axum-test/latest/axum_test/struct.TestRequest.html) against your application,
- receive back a [TestResponse](https://docs.rs/axum-test/latest/axum_test/struct.TestResponse.html),
- then assert the response is how you expect.
[TestServer](https://docs.rs/axum-test/latest/axum_test/struct.TestServer.html)

```

[TestRequest](https://docs.rs/axum-test/latest/axum_test/struct.TestRequest.html)

```

```

[TestResponse](https://docs.rs/axum-test/latest/axum_test/struct.TestResponse.html)

```
TestResponse

It includes built in support for serializing and deserializing request and response bodies using Serde, support for cookies and headers, and other common bits you would expect.
TestServer will pass http requests directly to the handler, or can be run on a random IP / Port address.
