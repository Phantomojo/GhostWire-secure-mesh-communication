This crate provides support for logging events and errors / panics to the [Sentry](https://sentry.io/) error logging service. It integrates with the standard panic system in Rust as well as a few popular error handling setups.

## [§](https://docs.rs/sentry/latest/sentry/#quickstart)Quickstart
[§](https://docs.rs/sentry/latest/sentry/#quickstart)
The most convenient way to use this library is via the [sentry::init](https://docs.rs/sentry/latest/sentry/fn.init.html) function, which starts a sentry client with a default set of integrations, and binds it to the current [[Hub](https://docs.rs/sentry/latest/sentry/struct.Hub.html)](https://docs.rs/sentry/latest/sentry/struct.Hub.html). More Information on how to use Sentry in parallel, concurrent and async scenarios can be found on the Hub docs as well.

```
sentry::init
```


```
Hub
```


```
Hub
```

The [sentry::init](https://docs.rs/sentry/latest/sentry/fn.init.html) function returns a guard that when dropped will flush Events that were not yet sent to the sentry service. It has a two second deadline for this so shutdown of applications might slightly delay as a result of this. Keep the guard around or sending events will not work.

```
sentry::init
```


```
let _guard = sentry::init("https://key@sentry.io/42"); sentry::capture_message("Hello World!", sentry::Level::Info); // when the guard goes out of scope here, the client will wait up to two // seconds to send remaining events to the service.
```


```
let _guard = sentry::init("https://key@sentry.io/42"); sentry::capture_message("Hello World!", sentry::Level::Info); // when the guard goes out of scope here, the client will wait up to two // seconds to send remaining events to the service.
```

More complex [examples](https://github.com/getsentry/sentry-rust/tree/master/sentry/examples) on how to use sentry can also be found in examples. Extended instructions may also be found on [Sentry itself](https://docs.sentry.io/platforms/rust).
