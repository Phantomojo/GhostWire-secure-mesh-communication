[Ratatui](https://ratatui.rs/) is a crate for cooking up terminal user interfaces in Rust. It is a lightweight library that provides a set of [widgets](https://docs.rs/ratatui/latest/ratatui/widgets/index.html) and utilities to build complex Rust TUIs. Ratatui was forked from the [tui-rs](https://crates.io/crates/tui) crate in 2023 in order to continue its development.

[§](https://docs.rs/ratatui/latest/ratatui/#quickstart)

```

use crossterm::event; fn main() -> std::io::Result<()> { ratatui::run(|mut terminal| { loop { terminal.draw(|frame| frame.render_widget("Hello World!", frame.area()))?; if event::read()?.is_key_press() { break Ok(()); } } }) }
```

## [§](https://docs.rs/ratatui/latest/ratatui/#writing-applications)Writing Applications
[§](https://docs.rs/ratatui/latest/ratatui/#writing-applications)
Ratatui is based on the principle of immediate rendering with intermediate buffers. This means that for each frame, your app must render all [widgets](https://docs.rs/ratatui/latest/ratatui/widgets/index.html) that are supposed to be part of the UI. This is in contrast to the retained mode style of rendering where widgets are updated and then automatically redrawn on the next frame. See the [Rendering](https://ratatui.rs/concepts/rendering/) section of the [Ratatui Website](https://ratatui.rs/) for more info.

```
widgets
```

Ratatui uses [Crossterm](https://crates.io/crates/crossterm) by default as it works on most platforms. See the [Installation](https://ratatui.rs/installation/) section of the [Ratatui Website](https://ratatui.rs/) for more details on how to use other backends ([Termion](https://crates.io/crates/termion) / [Termwiz](https://crates.io/crates/termwiz)).

### [§](https://docs.rs/ratatui/latest/ratatui/#drawing-the-ui)Drawing the UI
[§](https://docs.rs/ratatui/latest/ratatui/#drawing-the-ui)
Drawing the UI is done by calling the [Terminal::draw](https://docs.rs/ratatui/latest/ratatui/struct.Terminal.html#method.draw) method on the terminal instance. This method takes a closure that is called with a [[Frame](https://docs.rs/ratatui/latest/ratatui/struct.Frame.html)](https://docs.rs/ratatui/latest/ratatui/struct.Frame.html) instance. The Frame provides the size of the area to draw to and allows the app to render any [Widget](https://docs.rs/ratatui/latest/ratatui/prelude/trait.Widget.html) using the provided [render_widget](https://docs.rs/ratatui/latest/ratatui/struct.Frame.html#method.render_widget) method. After this closure returns, a diff is performed and only the changes are drawn to the terminal. See the [Widgets](https://ratatui.rs/recipes/widgets/) section of the [Ratatui Website](https://ratatui.rs/) and the [Widget Recipes](https://ratatui.rs/recipes/widgets/) for more info on creating effective UIs.

### [§](https://docs.rs/ratatui/latest/ratatui/#handling-events)Handling events

[§](https://docs.rs/ratatui/latest/ratatui/#layout-1)
The library comes with a basic yet useful layout management object called [[Layout](https://ratatui.rs/recipes/layout/)](https://docs.rs/ratatui/latest/ratatui/prelude/struct.Layout.html) which allows you to split the available space into multiple areas and then render widgets in each area. This lets you describe a responsive terminal UI by nesting layouts. See the Layout section of the [Ratatui Website](https://ratatui.rs/) for more info, and check out the [Layout Recipes](https://ratatui.rs/recipes/layout/) for practical examples.

```
Layout
```


```
use ratatui::Frame; use ratatui::layout::{Constraint, Layout}; use ratatui::widgets::Block; fn draw(frame: &mut Frame) { use Constraint::{Fill, Length, Min}; let vertical = Layout::vertical([Length(1), Min(0), Length(1)]); let [title_area, main_area, status_area] = vertical.areas(frame.area()); let horizontal = Layout::horizontal([Fill(1); 2]); let [left_area, right_area] = horizontal.areas(main_area); frame.render_widget(Block::bordered().title("Title Bar"), title_area); frame.render_widget(Block::bordered().title("Status Bar"), status_area); frame.render_widget(Block::bordered().title("Left"), left_area); frame.render_widget(Block::bordered().title("Right"), right_area); }
```
