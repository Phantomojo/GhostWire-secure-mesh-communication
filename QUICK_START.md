# 🛡️ GhostWire - Quick Start Guide

## 🚀 Launch GhostWire (The Easy Way)

**Just double-click or run:**
```bash
./RUN_GHOSTWIRE.sh
```

That's it! GhostWire will:
- ✅ Start the backend automatically
- ✅ Launch the web interface  
- ✅ Open in your browser
- ✅ Show the Afrofuturistic logo on login

## 🎨 What You'll See

### Login Screen
- **Glowing purple panther logo**
- Purple/gold gradient "GHOSTWIRE" text
- Vibranium-themed design

### Header (All Pages)
- **Logo with glow effect** (top left)
- Gradient text branding
- "Secure Mesh Network" tagline

### Dashboard
- Original clean interface
- Standard react-icons (not changed)
- Focus on functionality

## 💡 No Bash Knowledge Needed!

The `RUN_GHOSTWIRE.sh` script handles everything:
- Checks if services are running
- Installs dependencies (first time only)
- Opens your browser automatically
- Shows helpful status messages

## 🛑 To Stop GhostWire

Press `Ctrl+C` in the terminal where you ran the script.

## 📱 App-Like Experience

GhostWire runs as a web app in your browser, giving you:
- Fast, responsive UI
- Works on any OS
- No installation complexity
- Automatic updates
