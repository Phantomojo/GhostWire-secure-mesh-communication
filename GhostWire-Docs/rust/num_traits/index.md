<a href="trait.Num.html" class="trait"
title="trait num_traits::Num">Num</a>  
The base trait for numeric types, covering `0` and `1` values,
comparisons, basic numeric operations, and string conversion.

<a href="trait.NumAssign.html" class="trait"
title="trait num_traits::NumAssign">NumAssign</a>  
The trait for `Num` types which also implement assignment operators.

<a href="trait.NumAssignOps.html" class="trait"
title="trait num_traits::NumAssignOps">NumAssignOps</a>  
Generic trait for types implementing numeric assignment operators (like
`+=`).

<a href="trait.NumAssignRef.html" class="trait"
title="trait num_traits::NumAssignRef">NumAssignRef</a>  
The trait for `NumAssign` types which also implement assignment
operations taking the second operand by reference.

<a href="trait.NumOps.html" class="trait"
title="trait num_traits::NumOps">NumOps</a>  
Generic trait for types implementing basic numeric operations

<a href="trait.NumRef.html" class="trait"
title="trait num_traits::NumRef">NumRef</a>  
The trait for `Num` types which also implement numeric operations taking
the second operand by reference.

<a href="trait.RefNum.html" class="trait"
title="trait num_traits::RefNum">RefNum</a>  
The trait for `Num` references which implement numeric operations,
taking the second operand either by value or by reference.
