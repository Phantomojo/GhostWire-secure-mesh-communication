High-level network manager.
A [Swarm](https://docs.rs/libp2p/latest/libp2p/struct.Swarm.html) contains the state of the network as a whole. The entire behaviour of a libp2p network can be controlled through the Swarm. The Swarm struct contains all active and pending connections to remotes and manages the state of all the substreams that have been opened, and all the upgrades that were built upon these substreams.

## [§](https://docs.rs/libp2p/latest/libp2p/swarm/index.html#initializing-a-swarm)Initializing a Swarm
[§](https://docs.rs/libp2p/latest/libp2p/swarm/index.html#initializing-a-swarm)
Creating a Swarm requires three things:

```
Swarm
```

1. A network identity of the local node in form of a [PeerId](https://docs.rs/libp2p/latest/libp2p/struct.PeerId.html).
2. An implementation of the [Transport](https://docs.rs/libp2p/latest/libp2p/trait.Transport.html) trait. This is the type that will be used in order to
reach nodes on the network based on their address. See the transport module for more
information.
3. An implementation of the [NetworkBehaviour](https://docs.rs/libp2p/latest/libp2p/swarm/trait.NetworkBehaviour.html) trait. This is a state machine that defines
how the swarm should behave once it is connected to a node.

## [§](https://docs.rs/libp2p/latest/libp2p/swarm/index.html#network-behaviour)Network Behaviour
[§](https://docs.rs/libp2p/latest/libp2p/swarm/index.html#network-behaviour)
The [NetworkBehaviour](https://docs.rs/libp2p/latest/libp2p/swarm/trait.NetworkBehaviour.html) trait is implemented on types that indicate to the swarm how it should behave. This includes which protocols are supported and which nodes to try to connect to. It is the NetworkBehaviour that controls what happens on the network. Multiple types that implement NetworkBehaviour can be composed into a single behaviour.
