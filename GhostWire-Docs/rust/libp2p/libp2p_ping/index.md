This module implements the `/ipfs/ping/1.0.0` protocol.

The ping protocol can be used as a simple application-layer health check
for connections of any
[`Transport`](../libp2p_core/transport/trait.Transport.html "trait libp2p_core::transport::Transport")
as well as to measure and record round-trip times.

# <a href="#usage" class="doc-anchor">§</a>Usage

The [`Behaviour`](struct.Behaviour.html "struct libp2p_ping::Behaviour")
struct implements the
[`NetworkBehaviour`](../libp2p_swarm/behaviour/trait.NetworkBehaviour.html "trait libp2p_swarm::behaviour::NetworkBehaviour")
trait. It will respond to inbound ping requests and periodically send
outbound ping requests on every established connection.

It is up to the user to implement a health-check / connection management
policy based on the ping protocol.

For example:

-   Disconnect from peers with an RTT &gt; 200ms
-   Disconnect from peers which don’t support the ping protocol
-   Disconnect from peers upon the first ping failure

Users should inspect emitted
[`Event`](struct.Event.html "struct libp2p_ping::Event")s and call APIs
on
[`Swarm`](../libp2p_swarm/struct.Swarm.html "struct libp2p_swarm::Swarm"):

-   [`Swarm::close_connection`](../libp2p_swarm/struct.Swarm.html#method.close_connection "method libp2p_swarm::Swarm::close_connection")
    to close a specific connection
-   [`Swarm::disconnect_peer_id`](../libp2p_swarm/struct.Swarm.html#method.disconnect_peer_id "method libp2p_swarm::Swarm::disconnect_peer_id")
    to close all connections to a peer
