A crate offering integration with the MIO runtime.

There are different sub modules for supporting different MIO versions.
The support for a version must be activated by a feature flag:

-   `support-v0_6` for sub module \[`v0_6`\]
-   `support-v0_7` for sub module \[`v0_7`\]
-   `support-v0_8` for sub module \[`v0_8`\]
-   `support-v1_0` for sub module
    [`v1_0`](v1_0/index.html "mod signal_hook_mio::v1_0")

See the specific sub modules for usage examples.
