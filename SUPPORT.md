### **Support Scope**

**We Can Help With:**
- ✅ Installation and setup
- ✅ Configuration questions
- ✅ Bug troubleshooting
- ✅ Feature guidance
- ✅ Best practices
- ✅ Security concerns

**Out of Scope:**
- ❌ Custom development (unless contracted)
- ❌ Debugging your custom code
- ❌ Infrastructure setup
- ❌ General programming help
- ❌ Non-GhostWire issues

### **How to Get Better Support**

1. **Read Documentation First**
   - Check relevant docs before asking
   - Search existing issues/discussions

2. **Provide Context**
   - What are you trying to do?
   - What have you tried?
   - What's your environment?

3. **Include Details**
   - OS and version
   - GhostWire version
   - Error messages (full text)
   - Steps to reproduce

4. **Be Patient**
   - Community support is volunteer-based
   - Commercial support has SLAs
   - Respect maintainers' time

## ❓ Frequently Asked Questions

### **Q: How do I report a security vulnerability?**
**A:** Email mirungu015@proton.me or create a private GitHub security advisory. Do NOT create public issues for security matters.

### **Q: I need to use this commercially. Do I need a license?**
**A:** If you can comply with AGPL-3.0 (including source disclosure), no. Otherwise, yes. See [COMMERCIAL_LICENSE.md](COMMERCIAL_LICENSE.md).

### **Q: How fast is support?**
**A:** Community support varies. Commercial support has SLAs (24-48h depending on tier).

### **Q: Can I get priority support without a commercial license?**
**A:** No, priority support is for commercial license holders only.

### **Q: Do you offer training?**
**A:** Yes, for Enterprise license holders. Contact mirungu015@proton.me.

### **Q: Can I hire the team for custom development?**
**A:** Yes, Enterprise tier includes custom development. Contact us to discuss.
