### Tweet 2/8

GhostWire is a decentralized encrypted mesh communication platform built in Rust on libp2p.

Every device is a node. Every node is a router. No central point of failure.

When infrastructure fails, GhostWire keeps working.

Built in Nairobi, Kenya 🇰🇪

---

### Tweet 3/8

Here's what makes it different: AI-powered routing trained on REAL mesh data.

Not simulations. Not academic benchmarks.

7,931 samples from Barcelona's Guifi.net — one of the world's largest community mesh networks.

The AI learns from network experience and optimizes routing paths.

---

### Tweet 4/8

The 4-layer AI system:

L1: LightGBM anomaly detection — AUC 1.0, 91μs
L1b: Isolation Forest — ROC-AUC 0.918
L2: Gemma 4 mesh analysis — natural language topology review
L3: Graph Attention Network — routing optimization
L4: PRoPHET fallback — always available

---

### Tweet 5/8

Security is mandatory, not optional:

🔒 XChaCha20-Poly1305 + X25519 encryption
🔒 Forward secrecy via symmetric ratchet
🔒 Shamir Secret Sharing for key recovery
🔒 Anomaly detection for threat monitoring

There is no unencrypted mode. Period.
