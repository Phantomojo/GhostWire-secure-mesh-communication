# 🛡️ GhostWire Branding Guide

Welcome to the new visual identity of **GhostWire**. This project embraces an **Afrofuturistic** aesthetic, blending traditional African motifs with cutting-edge technology—inspired by the advanced nation of Wakanda.

## 🎨 Visual Philosophy
GhostWire is about stealth, security, and interconnectedness. Our branding reflects this through:
- **The Shield**: A futuristic Nguni shield representing protection and defense.
- **The Panther Mesh**: A glowing geometric panther head, symbolizing the "Ghost" in the wire—stealthy, powerful, and always connected.
- **Vibranium Palette**: Deep purples, glowing golds, and stealth blacks.

## 🔤 Wakandan Script
The name "GhostWire" has been translated into a futuristic script inspired by **Nsibidi** and **Tifinagh**. This script is used in our brand header to emphasize the "Ancient Future" theme.

**English:** GHOSTWIRE  
**Wakandan Style:** ᚷᚺᛟᛋᛏᚹᛁᚱᛖ (Stylized)

## 📦 Assets Directory
All assets are located in the `exports/` folder:

### 1. Logos
- `logo_final.png`: Main logo with transparent background.
- `brand_header.png`: Full brand banner with English and Wakandan script.

### 2. App Icons (`exports/app_icons/`)
- `favicon.ico`: For web use.
- `icon_1024x1024.png`: High-res app icon.
- Various sizes from 16x16 to 512x512.

### 3. Feature Icons (`exports/features/`)
- `feature_security.png`: Shield & Lock.
- `feature_mesh.png`: Interconnected Tribal Nodes.
- `feature_broadcast.png`: Djembe Drum Signal.
- `feature_lockdown.png`: Panther Claw Circuit.

## 🚀 How to Use
- **Web**: Use `favicon.ico` and `logo_final.png`.
- **Mobile**: Use the icons in `exports/app_icons/`.
- **Docs**: Use `brand_header.png` for README headers.
