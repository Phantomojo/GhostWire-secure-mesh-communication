# Product Hunt Launch

## Product Name
GhostWire

## Tagline
Decentralized mesh communication that works without internet

## Description
GhostWire is a peer-to-peer encrypted communication platform built for when
traditional infrastructure fails. No servers. No owners. Built in Rust with
AI-powered routing.

When disasters strike, cell towers go down. When communities are remote,
nobody builds infrastructure. GhostWire lets devices communicate directly —
hopping node-to-node through WiFi, Bluetooth, LoRa, or any available path.

## Maker Comment (posted on launch day)
Hey Product Hunt! 👋

I'm Michael, a cybersecurity student from Nairobi, Kenya. I built GhostWire
because I've seen what happens when communities lose connectivity — families
can't check on each other after floods, rescue teams can't coordinate, and
activists can't organize safely.

GhostWire is:
🔒 End-to-end encrypted (AES-256-GCM + X25519)
🌐 Serverless — pure P2P mesh networking
🤖 AI-powered routing trained on real mesh data
📡 7 transport layers with auto-fallback
🍏 Runs on a Raspberry Pi

It's open source (AGPL-3.0) and we're looking for contributors. Check out
the GitHub repo for good first issues!

Built in Nairobi, for the world. 🇰🇪
