// plan

Product Vision

We are building in three phases: laying a secure Rust core, adding modular transports for off-grid operations, and integrating post-quantum resilience.

Now

Security

vodozemac Olm/Megolm E2EE

Harden and audit double-ratchet session establishment layers for forward secrecy and session state recovery.

Transport

obfs4 pluggable transport

Wire obfs4 morphing directly into the libp2p network stack to disguise TCP mesh traffic as standard TLS/HTTPS.

Bridges

Briar & Reticulum bridges

Refine protocol adapter performance in briar.rs and reticulum.rs to support seamless routing across protocols.

Next

Transport

Bluetooth LE Mesh

Move the Bluetooth Low Energy transport from mock/skeleton state to a fully-realized direct mesh for mobile devices.

Transport

LoRa & RF transport

Implement off-grid LoRa radio communication via modular hardware bridges (such as Meshtastic T-Beam devices).

Platform

Mobile clients compilation

Provide Android (APK) and iOS client builds utilizing Tauri v2/React Native wrappers for mobile mesh networks.

Later

Post-Quantum

ML-KEM-768 encapsulation

Integrate NIST-standardized Kyber post-quantum key encapsulation to protect mesh traffic from future quantum decryptors.

Audit

Third-party security audit

Engage a reputable third-party security firm to audit the entire cryptographic and P2P transport implementation.

Identity

Decentralized DNS routing

Build an out-of-band peer identification and name registry to discover nodes and resolve routes without global directories.
