// how it works

Mesh networking for the real world

01

No central server

Devices connect directly via libp2p. Messages hop node-to-node through whatever path is available. Remove any node — the mesh routes around it. Pure P2P, no single point of failure.

02

7 transport layers

WiFi Direct, Bluetooth LE, LoRa radio, WebRTC, TCP/IP, Reticulum, Briar. GhostWire selects the best available path. No internet? It falls back to RF mesh automatically.

03

AI-powered routing

LightGBM anomaly detection (76.7μs inference, ONNX exported) + GNN routing trained on real GuifiSants mesh data. The network learns from experience to optimize delivery paths.

04

End-to-end encrypted

AES-256-GCM authenticated encryption. X25519 key exchange with perfect forward secrecy. Post-quantum ML-KEM-768 integration. No server ever sees plaintext.

05

Delay-tolerant delivery

Messages queue when peers are offline. Delivered when the network reconnects. PRoPHET protocol for epidemic routing. Works in intermittent connectivity by design.

// protocol stack

Built on proven cryptographic foundations

Encryption

AES-256-GCM

Industry-standard authenticated encryption. All messages encrypted end-to-end. Hardware-accelerated via Rust crypto libraries. No server ever sees plaintext.

Key Exchange

Ed25519 / X25519

Modern elliptic curve cryptography. Perfect forward secrecy through ephemeral key rotation. Identity keys never leave your device. Implemented in the Rust crypto_machine module.

Post-Quantum

ML-KEM-768

NIST-standardized post-quantum key encapsulation. Protects against future quantum computers. Implemented today, not tomorrow.

Networking

libp2p + Kademlia DHT

Proven P2P networking used by IPFS and Ethereum. Gossipsub messaging. S/Kademlia-hardened routing. Tokio async runtime for high-throughput concurrency.

AI Routing

LightGBM + GNN

L1 LightGBM anomaly detector: AUC 1.0, 76.7μs inference, ONNX exported. L3 GNN trained on 7,931 real GuifiSants samples. Models wired into Rust via ONNX Runtime.

Defense

Sybil resistance

Proof-of-work node admission. Quota enforcement. Blacklist management. Reputation system with TrustStore. Protects the mesh from fake node attacks.

Privacy

Traffic obfuscation

Cover traffic generation. Timing randomization. Metadata minimization. Stealth TCP transport. Makes traffic analysis significantly harder for network-level adversaries.

Monitoring

Real-time dashboard

Interactive mesh topology visualization. Live CPU, RAM, and network metrics. Peer health monitoring. Axum HTTP API with JSON endpoints at localhost:8080.

Identity

Multi-profile support

Separate identities for different contexts. Community coordinator, disaster responder, privacy advocate profiles. Username discovery. QR code peer pairing.

// transparency

What GhostWire does NOT protect against

Honest security requires honest limitations. GhostWire is a tool, not a guarantee.

⚠

Physical device seizure

If your device is seized, local data may be at risk. Use full-disk encryption and enable GhostWire's lockdown mode for high-threat environments.

⚠

Full anonymity

GhostWire provides strong privacy, not complete anonymity. Traffic analysis by a well-resourced adversary monitoring all mesh nodes remains a risk.

⚠

Endpoint compromise

Encryption protects messages in transit. If the device at either end is compromised by malware, GhostWire cannot protect the content at that endpoint.

⚠

Not yet independently audited

GhostWire has not yet undergone an independent third-party security audit. Use accordingly. We will publish audit reports when completed. Internal audits are in docs/AUDIT_REPORT.md.

// quick start

Running in under 5 minutes

# Clone and install
git clone https://github.com/Phantomojo/GhostWire-secure-mesh-communication.git
cd GhostWire-secure-mesh-communication
./scripts/install.sh

# Start GhostWire
./scripts/ghostwire.sh start

# Open the dashboard
http://localhost:8080
# Pull and run
docker-compose up -d

# Check health
curl http://localhost:9000/api/v2/health

# Expected output
{"status":"healthy","version":"0.1.0"}
# Prerequisites: Rust 1.75+, Node 18+
git clone https://github.com/Phantomojo/GhostWire-secure-mesh-communication.git
cd GhostWire-secure-mesh-communication/ghostwire

# Build the backend
cargo build --release

# Build the frontend
cd ../webui-src && npm install && npm run build
